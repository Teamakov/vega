# Викторина по курсу «Управление группой»

Вопросы для закрепления материала сессий 1-4: Павлов, Парлетт, Ялом, Джозеф и Глория Мельник, Соня Невис, Эдвин Невис, Стефани Бэкман, а также лекции Павлова на сессиях 1-3.

192 вопроса, у каждого три варианта ответа. Из них 49 - по записям лекций Павлова, отдельной карточкой. После ответа показывается объяснение и источник. Прогресс сохраняется в браузере.

Сайт - один файл `index.html`, работает и без интернета.
