# Викторина по курсу «Управление группой»

Вопросы для закрепления материала сессий 1-4: Павлов, Парлетт, Ялом, Джозеф и Глория Мельник, Соня Невис, Эдвин Невис, Стефани Бэкман.

152 вопроса, у каждого три варианта ответа. После ответа показывается объяснение и источник. Прогресс сохраняется в браузере.

Сайт - один файл `index.html`, работает и без интернета.
